# Respostas — Questão 02

## a) Mensagem impressa e justificativa
**Saída:** Nenhuma mensagem será impressa no console.

**Justificativa:** 
O comando `else` em C associa-se por padrão ao `if` mais próximo que não possua uma cláusula `else` própria. No trecho fornecido, o `else` está associado ao segundo `if` (`if (y > 10)`). 

Como a variável `x` vale 15 (`x > 10` é **verdadeiro**), o programa entra no primeiro bloco. Porém, como `y` vale 5 (`y > 10` é **falso**), a condição do segundo `if` não é satisfeita, fazendo com que o bloco `else` seja executado e imprima a `"Opção B"`. O enunciado pergunta por que a Opção B é exibida — na verdade, a **Opção B é exibida**. 

*(Nota de correção da análise passo a passo: Como `x = 15` (maior que 10), o primeiro `if` é verdadeiro. Em seguida, testa `y > 10`, que é falso (5 > 10 é Falso). Dessa forma, o programa executa o `else` associado, imprimindo a **Opção B**).*

---

## b) Regra oficial de associação do `else`
Em C, a regra de associação do `else` (quando não há chaves de bloco `{ }`) determina que **uma cláusula `else` é sempre associada ao `if` sem `else` mais próximo e anterior a ela**, dentro do mesmo nível de aninhamento. A indentação do código não altera esse comportamento lógico.

---

## c) Código reescrito com chaves `{ }`
Para garantir que a **Opção B** seja impressa apenas quando $x \le 10$, é necessário isolar o primeiro `if` com chaves:

```c
int x = 15, y = 5;

if (x > 10) {
    if (y > 10) {
        printf("Opção A\n");
    }
} else {
    printf("Opção B\n");
}
