## Questão 03. Operador Condicional Ternário vs. Estrutura if-else

### a) Funcionamento e Avaliação
A linha de código `situacao = (media >= 7.0) ? 'A' : 'R';` funciona da seguinte forma:

1. Avalia a condição lógica `(media >= 7.0)`.
2. Se a condição for **verdadeira**, o operador retorna o primeiro valor (antes dos dois pontos `:`), que é `'A'`.
3. Se a condição for **falsa**, o operador retorna o segundo valor (depois dos dois pontos `:`), que é `'R'`.
4. O valor retornado é então atribuído à variável `situacao`.

**Resultado para `media = 6.8`:**  
Como `6.8 >= 7.0` é **falso**, a expressão retorna `'R'`. Portanto, a variável `situacao` armazenará o caractere `'R'`.

---

### b) Reescrita com Estrutura `if-else`

```c
media = (nota1 + nota2) / 2.0;

if (media >= 7.0) {
    situacao = 'A';
} else {
    situacao = 'R';
}
```
---
### c) Limitações do Operador Ternário   
Não, o operador ternário não pode substituir qualquer estrutura if-else.   

Limitações:   

Expressão vs. Instrução: O operador ternário é uma expressão que produz e retorna um único valor. Ele não é apropriado para executar blocos complexos de instruções sem retorno (como sequências de printf, laços de repetição, chamadas de funções com efeitos colaterais ou múltiplas declarações).   

Múltiplos Comandos: Embora seja possível utilizar o operador vírgula para executar múltiplas expressões dentro de cada ramo do ternário, isso compromete gravemente a legibilidade e a manutenibilidade do código, violando as boas práticas de programação em C.   

Legibilidade e Aninhamento: Em tomadas de decisão com múltiplos ramos (else-if) ou regras de negócio complexas, o uso de operadores ternários aninhados torna o código extremamente confuso e difícil de entender em comparação à estrutura if-else tradicional.
