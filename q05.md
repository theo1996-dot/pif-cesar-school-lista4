# Questão 05. Avaliação de Curto-Circuito em Operadores Lógicos

## a) Saída do programa e explicação

**Saída exata no terminal:**

```text
a = 0, b = 5, c = 8
```

**Explicação:**

A variável `a` possui valor `0`. Portanto, a condição `a != 0` é falsa.

Como o operador lógico `&&` (E) exige que as duas condições sejam verdadeiras, o programa não precisa avaliar a segunda condição (`++b > 5`).

Assim, o incremento `++b` não é executado, e a variável `b` continua com valor `5`.

Como a condição do `if` é falsa, o bloco `else` é executado, realizando a operação `c -= 2`. Dessa forma, `c` passa de `10` para `8`.

## b) Conceito de avaliação de curto-circuito

A avaliação de curto-circuito (*short-circuit evaluation*) ocorre quando o programa deixa de avaliar uma expressão lógica porque já é possível determinar o resultado final.

**Operador lógico E (`&&`):**

O operador `&&` retorna verdadeiro somente quando as duas condições são verdadeiras. Se a primeira condição for falsa, a segunda não será avaliada, pois o resultado da expressão já será falso.

Exemplo:

```c
if (a != 0 && ++b > 5)
```

Se `a` for igual a `0`, a primeira condição será falsa. Portanto, `++b` não será executado.

**Operador lógico OU (`||`):**

O operador `||` retorna verdadeiro quando pelo menos uma das condições é verdadeira. Se a primeira condição for verdadeira, a segunda não será avaliada, pois o resultado da expressão já será verdadeiro.

Exemplo:

```c
if (a == 0 || ++b > 5)
```

Se `a` for igual a `0`, a primeira condição será verdadeira. Portanto, `++b` não será executado.

## c) Valores finais de `b` e `c` com a condição alterada

Considerando a condição:

```c
if (a == 0 || ++b > 5)
    c += 10;
else
    c -= 2;
```

**Valores iniciais:**

- `a = 0`
- `b = 5`
- `c = 10`

**Explicação:**

1. A primeira condição, `a == 0`, é verdadeira.
2. Como o operador `||` precisa apenas de uma condição verdadeira, a segunda expressão (`++b > 5`) não é avaliada.
3. Portanto, `b` permanece com valor `5`.
4. Como a condição do `if` é verdadeira, o comando `c += 10` é executado.
5. Assim, `c` passa de `10` para `20`.

**Valores finais:**

- `b = 5`
- `c = 20`

**Conclusão:** A avaliação de curto-circuito evita a execução desnecessária da segunda expressão lógica. No operador `&&`, isso ocorre quando a primeira condição é falsa; no operador `||`, ocorre quando a primeira condição é verdadeira.
