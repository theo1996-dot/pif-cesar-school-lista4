# Questão 06. Construções `else-if` e Análise Lógica de Intervalos

## a) Saída do programa para `idade = 65`

**Saída exata no terminal:**

```text
Idoso
Adulto
Jovem
```

**Explicação:**

Como a idade é `65`, as três primeiras condições são verdadeiras:

- `idade >= 60`: verdadeira, imprime `Idoso`.
- `idade >= 18`: verdadeira, imprime `Adulto`.
- `idade >= 12`: verdadeira, imprime `Jovem`.

O comando `else` está associado ao terceiro `if` (`idade >= 12`). Como essa condição é verdadeira, o `else` não é executado.

Múltiplas mensagens são exibidas porque os comandos `if` são independentes, permitindo que todas as condições verdadeiras sejam executadas.

## b) Diferença entre `if` independentes e uma cadeia `else-if`

**`if` independentes:**

Cada condição é verificada separadamente. Se várias condições forem verdadeiras, todos os blocos correspondentes serão executados, podendo imprimir várias mensagens.

**Cadeia `else-if`:**

As condições são verificadas em sequência. Quando uma condição é verdadeira, seu bloco é executado e as demais condições da cadeia são ignoradas. Dessa forma, apenas uma categoria é selecionada.

Portanto, a estrutura `else-if` é mais adequada quando as categorias são mutuamente exclusivas, como na classificação de faixas etárias.

## c) Programa reescrito utilizando `else-if`

```c
#include <stdio.h>

int main() {
    int idade = 65;

    if (idade >= 60) {
        printf("Idoso\n");
    } else if (idade >= 18) {
        printf("Adulto\n");
    } else if (idade >= 12) {
        printf("Jovem\n");
    } else {
        printf("Criança\n");
    }

    return 0;
}
```

**Explicação:**

A estrutura `else-if` verifica as condições em sequência, da maior faixa etária para a menor. Como a primeira condição é verdadeira para `idade = 65`, apenas a mensagem `Idoso` será impressa.

**Saída exata no terminal:**

```text
Idoso
```

Dessa maneira, o programa garante que apenas uma categoria seja exibida para cada idade.
